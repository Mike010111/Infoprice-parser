# InfoPrice Parser

Java-приложение для автоматизированного сбора и анализа данных об акционных товарах из внешнего источника. Сервис получает данные постранично, объединяет цены одного товара по разным магазинам в единую таблицу и предоставляет результат через веб-интерфейс с выгрузкой в Excel.

**Demo:** https://infoprice-parser.onrender.com

---

## Что делает проект

1. Пользователь запускает сканирование одной кнопкой в браузере.
2. Backend в фоновом режиме собирает данные, не блокируя интерфейс.
3. На экране в реальном времени отображается прогресс выполнения.
4. Результат — таблица товаров с ценами по всем магазинам — доступен сразу в браузере.
5. Готовый Excel-отчёт формируется автоматически и скачивается одним кликом.

## Технологии

| Категория | Стек |
|---|---|
| Backend | Java 21, встроенный `HttpServer`, Maven |
| Обработка данных | Jackson (JSON), Apache POI (Excel) |
| Многопоточность | Фоновая обработка задач, безопасный конкурентный доступ к состоянию |
| Frontend | HTML, CSS, JavaScript (без фреймворков) |
| Инфраструктура | Docker (двухэтапная сборка), деплой на Render |
| Безопасность | Конфиденциальные параметры вынесены в переменные окружения |

---

## Ключевые инженерные решения

- **Асинхронная обработка.** Сбор данных выполняется в отдельном потоке, поэтому интерфейс остаётся отзывчивым, а пользователь видит живой прогресс вместо «зависшей» страницы.
- **Готовый результат без задержек.** Excel-отчёт формируется сразу после завершения сбора данных и хранится в памяти — скачивание происходит мгновенно, без повторного ожидания.
- **Безопасное хранение конфигурации.** Все чувствительные параметры вынесены из кода в переменные окружения и не публикуются в репозитории — стандартная практика для production-приложений.
- **Контейнеризация.** Приложение упаковано в Docker с раздельными этапами сборки и запуска, что уменьшает размер итогового образа и упрощает деплой на любую облачную платформу.

## Запуск проекта

```bash
mvn clean package
java -jar target/app.jar
```

Приложение будет доступно на `http://localhost:8080`.

Или через Docker:

```bash
docker build -t infoprice-parser .
docker run --rm -p 8080:8080 infoprice-parser
```

Перед запуском создайте файл `.env` по образцу `.env.example` и заполните необходимые значения.
